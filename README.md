# Notch Music

macOS 노치에 붙는 작은 Now Playing 컨트롤러입니다. YouTube Music을 포함한 macOS 시스템 미디어 세션을 감지하고, 재생을 시작하면 패널이 다이나믹 아일랜드처럼 확장됩니다.

## 실행

macOS 14 이상에서:

```bash
swift run NotchMusic
```

일반 앱처럼 더블클릭해서 실행하려면:

```bash
./Scripts/build-app.sh
open "dist/Notch Music.app"
```

완성된 앱은 `dist/Notch Music.app`에 생성됩니다. Dock에는 나타나지 않고 메뉴 막대의 음표 아이콘에서 노치를 열거나, 설정을 변경하거나, 앱을 종료할 수 있습니다.

Chrome 또는 Safari에서 YouTube Music을 재생하면 자동으로 감지됩니다. 앱은 메뉴 막대의 음표 아이콘에서 수동으로 열거나 종료할 수 있습니다.

## 현재 지원

- 노치 중앙에 항상 표시되는 컴팩트 바
- 새 곡 재생 시 스프링 확장 애니메이션
- YouTube Music, Spotify, Apple Music 및 시스템 Now Playing 지원 앱 감지
- 곡명, 아티스트, 앨범 아트
- 이전 / 재생·일시정지 / 다음
- 진행률 바 클릭·드래그로 재생 위치 이동
- 전체 화면 및 모든 Space 위에 표시
- 새 곡 자동 펼침 및 자동 접힘 시간 설정
- 음악이 없을 때 실제 노치 폭으로 숨고, 음악 감지 시 양옆으로 펼쳐지는 컴팩트 애니메이션
- 앨범 표지, 진행률, 이퀄라이저, 호버 효과 표시 설정
- 강조 색상 변경 및 애니메이션 움직임 줄이기
- 펼친 화면에만 적용되는 macOS 26 네이티브 리퀴드 글래스 효과
- 외부 모니터가 주 화면이어도 내장 MacBook 디스플레이에 고정
- 외부 화면 선택 시 메뉴 막대 아래 전용 플로팅 플레이어 디자인

## 설정

메뉴 막대의 음표 아이콘을 누르고 `설정…`을 선택합니다. 모든 변경 내용은 즉시 적용되며 앱을 다시 실행해도 유지됩니다.

기본 표시 위치는 `내장 디스플레이`입니다. 설정의 `디스플레이`에서 `현재 주 디스플레이`를 선택하면 외부 모니터가 주 화면일 때 물리 노치 대신 전용 플로팅 디자인으로 표시됩니다. 내장 화면을 사용할 수 없는 클램셸 모드에서는 연결된 주 화면으로 자동 대체됩니다.

재생 위치를 이동하려면 노치를 펼친 뒤 진행률 바를 클릭하거나 좌우로 드래그합니다. 라이브 방송처럼 전체 재생 시간이 제공되지 않는 미디어에서는 위치 이동이 비활성화됩니다.

## MediaRemote 참고

이 프로젝트는 다른 앱의 시스템 Now Playing 정보를 가져오기 위해 macOS 비공개 `MediaRemote` 프레임워크를 런타임에 불러옵니다. 개인 배포에는 사용할 수 있지만 Mac App Store 제출에는 적합하지 않습니다. macOS 업데이트로 내부 API가 변경되면 어댑터 수정이 필요할 수 있습니다.
